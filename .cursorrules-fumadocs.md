# Recomendações do Cursor - Convenções Fumadocs

Este documento contém recomendações baseadas nas [convenções do Fumadocs](https://fumadocs.dev/docs/ui/page-conventions) para o projeto de documentação Homio.

## 📋 Estrutura de Arquivos

### Meta.json na Raiz
**CRÍTICO**: Criar um arquivo `meta.json` em `content/docs/` para controlar a ordem e organização das páginas no sidebar.

A ordem sugerida baseada no `index.mdx`:
1. **Configuração inicial** - Domínios
2. **Usuários e Permissões** - Para planos que permitem múltiplos usuários
3. **Comunicação** - WhatsApp, SMS, E-mail e Redes Sociais
4. **Funcionalidades avançadas** - Outras funcionalidades

### Estrutura Recomendada do meta.json

```json
{
  "title": "Documentação Homio",
  "pages": [
    "index",
    "---Configuração---",
    "dominios",
    "usuarios-e-permissoes",
    "informacoes-sub-conta",
    "download-aplicativo",
    "---Comunicação---",
    "(whatsapp-homio-meta)",
    "email",
    "ligacoes-sms",
    "redes-sociais"
  ]
}
```

## 📁 Organização de Pastas

### Folders com Parênteses
Se uma pasta não deve afetar os slugs dos arquivos filhos, ela deve estar entre parênteses.

**Exemplo**: 
- Pasta atual: `whatsapp-homio-meta/` → Gera slugs: `/whatsapp-homio-meta/whatsapp-homio`
- Pasta recomendada: `(whatsapp-homio-meta)/` → Gera slugs: `/whatsapp-homio` (sem o prefixo da pasta)

**Ação recomendada**: Renomear `content/docs/whatsapp-homio-meta/` para `content/docs/(whatsapp-homio-meta)/` se os slugs devem ser diretos.

### Root Folders
Para criar tabs no sidebar (útil para separar documentação por módulos), usar `"root": true` no `meta.json`:

```json
{
  "title": "Nome do Módulo",
  "root": true
}
```

## 📄 Frontmatter Obrigatório

Todos os arquivos MDX devem ter frontmatter com pelo menos:

```mdx
---
title: Título da Página
description: Descrição da página
---
```

**Campos opcionais**:
- `icon`: Nome do ícone (usando Lucide Icons via `lucideIconsPlugin`)
- Outros campos customizados via schema em `source.config.ts`

## 🔗 Slugs e Rotas

### Como os Slugs são Gerados

| Caminho do arquivo | Slug gerado |
|-------------------|-------------|
| `./dominios.mdx` | `['dominios']` |
| `./whatsapp-homio-meta/index.mdx` | `['whatsapp-homio-meta']` |
| `./whatsapp-homio-meta/whatsapp-homio.mdx` | `['whatsapp-homio-meta', 'whatsapp-homio']` |
| `.(whatsapp-homio-meta)/whatsapp-homio.mdx` | `['whatsapp-homio']` |

### Boas Práticas
- Use `index.mdx` em pastas para criar rotas com o nome da pasta
- Use parênteses em pastas que são apenas organizacionais
- Mantenha nomes de arquivos em kebab-case (ex: `usuarios-e-permissoes.mdx`)

## 📝 Controle de Páginas no meta.json

### Tipos de Entradas no Array `pages`

1. **Path simples**: `"dominios"` - Referencia um arquivo
2. **Separador**: `"---Configuração---"` - Cria um separador visual no sidebar
3. **Pasta**: `"(whatsapp-homio-meta)"` - Inclui todas as páginas da pasta (ordenadas pelo meta.json interno)
4. **Rest**: `"..."` - Inclui todas as páginas não listadas (ordenadas alfabeticamente)
5. **Exclusão**: `"!arquivo"` - Exclui um item do Rest
6. **Links externos**: `"[Texto](https://url.com)"` - Adiciona links externos no sidebar

### Exemplo Completo

```json
{
  "pages": [
    "index",
    "---Configuração---",
    "dominios",
    "usuarios-e-permissoes",
    "---Comunicação---",
    "(whatsapp-homio-meta)",
    "email",
    "ligacoes-sms",
    "redes-sociais",
    "---Recursos---",
    "...",
    "!arquivo-excluido"
  ]
}
```

## ✅ Checklist ao Criar/Modificar Páginas

- [ ] Arquivo MDX tem frontmatter com `title` e `description`
- [ ] Nome do arquivo está em kebab-case
- [ ] Página foi adicionada ao `meta.json` se necessário (ou está no Rest `...`)
- [ ] Se criar uma pasta, verificar se deve usar parênteses
- [ ] Se criar uma pasta, criar `meta.json` interno se precisar ordenar páginas
- [ ] Verificar que os slugs gerados estão corretos

## 🔍 Verificação de Configuração

### Verificar se a configuração está correta:

1. **source.config.ts**: Configuração do Fumadocs MDX está correta
2. **src/lib/source.ts**: Loader está usando o `lucideIconsPlugin` para ícones
3. **content/docs/meta.json**: Existe e controla a ordem das páginas
4. **Frontmatter**: Todos os arquivos MDX têm frontmatter completo

## 🚫 Erros Comuns a Evitar

1. **Não criar meta.json na raiz**: As páginas aparecerão em ordem alfabética
2. **Usar pastas sem parênteses quando não necessário**: Afeta os slugs desnecessariamente
3. **Esquecer frontmatter**: A página pode não ter título/descrição corretos
4. **Não ordenar páginas**: Deixar apenas o Rest `...` pode criar ordem aleatória
5. **Misturar organização**: Não seguir a estrutura sugerida no `index.mdx`
